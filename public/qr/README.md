# QR codes

Static QR images for Vietnam payment accounts. Add the image file here (PNG/JPEG/WebP), then in
Admin → Tài khoản nhận tiền set the account's "Đường dẫn ảnh QR" to `/qr/<filename>`.

This is a project asset, not an upload: adding or changing a QR means adding the file to this
folder, committing, and deploying — same as any other static asset in `public/`.
